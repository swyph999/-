# 二、贝叶斯推断的三个核心概念

假设： $x$ 为相机位置（未知）， $z$ 为观测数据（已知）。

1. **先验概率 $P(x)$**：获得观测前，对相机位置的概率估计。

2. **似然 $P(z\mid x)$**：假设相机位于 $x$，产生当前观测 $z$ 的可能性。

3. **后验概率 $P(x\mid z)$**：结合先验和观测信息，更新相机位置的概率估计。

**贝叶斯公式连接这三者的关系：**

```math
\boxed{P(x\mid z)=\frac{P(z\mid x)P(x)}{P(z)}}
```

其中， $P(z)$ 为归一化项。可以认为是已知常数

**总结：** 先验是观测前的判断，似然衡量假设位置对观测的解释程度，后验是结合观测后更新的判断。

# 三、基于最大后验估计（MAP）的 SLAM 状态优化，主要是引出最小二乘

## 1. 最大后验估计

已知上一时刻状态 $x_{k-1}$、控制量 $u_k$ 和当前观测 $z_k$，求当前状态 $x_k$ 的最优估计：

```math
\boxed{
x_k^*=\arg\max_{x_k}P(x_k\mid z_k,u_k,x_{k-1})
}
```

根据**贝叶斯公式**：

```math
P(x_k\mid z_k,u_k,x_{k-1})
=
\frac{
P(z_k\mid x_k)P(x_k\mid x_{k-1},u_k)
}{
P(z_k\mid x_{k-1},u_k)
}
```

其中：

- $P(z_k\mid x_k)$：观测似然，表示当前状态对观测数据的解释程度。
- $P(x_k\mid x_{k-1},u_k)$：预测分布，表示根据运动模型预测当前状态的概率。
- $P(z_k\mid x_{k-1},u_k)$：归一化项，相对于待优化变量 $x_k$ 是常数。

上述拆分假设：给定 $x_k$ 后，观测 $z_k$ 与过去状态、控制量条件独立。

因此，最大后验估计等价于：

```math
\boxed{
x_k^*=\arg\max_{x_k}
P(z_k\mid x_k)P(x_k\mid x_{k-1},u_k)
}
```

## 2. 建立高斯概率模型

### 2.1 观测模型

```math
z_k=h(y_j,x_k)+v_k
```

假设观测噪声满足零均值高斯分布：

```math
v_k\sim\mathcal{N}(0,Q_k)
```

因此：

```math
\boxed{
z_k\mid x_k\sim\mathcal{N}(h(y_j,x_k),Q_k)
}
```

其中：

- $h(y_j,x_k)$：观测预测函数，$y_j$ 为已知地图点。
- $Q_k$：观测噪声的协方差矩阵。

### 2.2 运动模型

```math
x_k=f(x_{k-1},u_k)+w_k
```

假设运动噪声满足零均值高斯分布：

```math
w_k\sim\mathcal{N}(0,R_k)
```

因此：

```math
\boxed{
x_k\mid x_{k-1},u_k
\sim\mathcal{N}(f(x_{k-1},u_k),R_k)
}
```

其中：

- $f(x_{k-1},u_k)$：运动模型预测的当前状态。
- $R_k$：运动噪声的协方差矩阵。

## 3. 高斯分布与负对数变换

多维高斯概率密度函数：

```math
\boxed{
P(x)=\frac{1}{\sqrt{(2\pi)^n\det(\Sigma)}}
\exp\left(-\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)\right)
}
```

其中：

- $\mu$：均值向量。
- $\Sigma$：协方差矩阵。
- $n$：随机变量维度。

由于对数函数单调递增：

```math
\boxed{
\arg\max_x P(x)=\arg\min_x[-\ln P(x)]
}
```

对高斯分布取负对数：

```math
-\ln P(x)
=
\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)
+
\frac12\ln\left((2\pi)^n\det(\Sigma)\right)
```

当 $\Sigma$ 不依赖于待优化变量 $x$ 时，后一项为常数，不影响最优解的位置。

因此：

```math
\boxed{
\arg\max_xP(x)
=
\arg\min_x
\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)
}
```

**结论：** 最大化高斯概率密度，等价于最小化对应的加权平方误差。

## 4. 将 MAP 转化为最小二乘问题

回到之前的 MAP 优化：

```math
x_k^*=\arg\max_{x_k}
P(z_k\mid x_k)P(x_k\mid x_{k-1},u_k)
```

两边取负对数，将乘积转化为求和：

```math
\boxed{
x_k^*=\arg\min_{x_k}
\left[
-\ln P(z_k\mid x_k)
-\ln P(x_k\mid x_{k-1},u_k)
\right]
}
```

分别代入观测模型与运动模型的高斯概率密度，并去掉与 $x_k$ 无关的常数项：

```math
\boxed{
\begin{aligned}
x_k^*=\arg\min_{x_k}\Bigg\{
&\frac12[z_k-h(y_j,x_k)]^TQ_k^{-1}[z_k-h(y_j,x_k)]\\
+&\frac12[x_k-f(x_{k-1},u_k)]^TR_k^{-1}[x_k-f(x_{k-1},u_k)]
\Bigg\}
\end{aligned}
}
```

定义两个残差：

**观测残差：**

```math
e_z=z_k-h(y_j,x_k)
```

**运动残差：**

```math
e_x=x_k-f(x_{k-1},u_k)
```

最终得到：

```math
\boxed{
x_k^*=\arg\min_{x_k}
\left[
\frac12e_z^TQ_k^{-1}e_z
+
\frac12e_x^TR_k^{-1}e_x
\right]
}
```

这就是一个**加权非线性最小二乘问题**。

其中：

- $e_z^TQ_k^{-1}e_z$：观测误差项。
- $e_x^TR_k^{-1}e_x$：运动预测误差项。
- $Q_k^{-1}$、$R_k^{-1}$：信息矩阵，决定不同误差的权重。

**总结：**

最大后验估计（MAP）→ 贝叶斯公式拆分 → 假设高斯噪声 → 取负对数 → 加权非线性最小二乘。
